rclone (Cloud storage and Remote connections)
=============================================

NOT bundled in the APK. The first time Cloud or Remote is opened, BFE offers to download it once from
BFE's own GitHub release, checks it against a SHA-256 pinned in the app, and runs it from BFE's private
storage:

  release tag   rclone-v1.75.2-android-arm64  (https://github.com/The412Banner/BFE/releases)
  download      rclone-v1.75.2-android-arm64.gz    14,998,988 bytes
                sha256 259868b5842e39200828cd853d7948339ab989aeb47381ee37dc360f7ceed34b
  executable    rclone (unpacked to files/bin/)    47,616,352 bytes
                sha256 190151335ba679eda9b67bd17099e9af9fb6162a9f5bdd9a52c099b52ca2c6c2
  reports       rclone v1.75.2-bfe

What it is: rclone v1.75.2 (https://rclone.org, source https://github.com/rclone/rclone, tag v1.75.2,
commit be8d6044eacb843b74d335db0c5fbe09222031fe), unmodified, built with a smaller main package
(rclone/main.go in the BFE repository) that links only the commands and storage backends BFE uses:
Google Drive, OneDrive, Dropbox, Box, pCloud, MEGA, Proton Drive, Yandex Disk, WebDAV (Nextcloud,
ownCloud), S3 (AWS, Wasabi, Cloudflare R2, MinIO and others), Backblaze B2, SFTP, FTP, SMB, HTTP,
local, crypt, combine and union.

Reproducible build: .github/workflows/build-rclone.yml - GitHub Actions, ubuntu-22.04, Go 1.26.9,
Android NDK r29 (29.0.14206865), GOOS=android GOARCH=arm64 CGO_ENABLED=1 (links against bionic),
target aarch64-linux-android26, `go build -tags android -trimpath -ldflags "-s -w"`. Two separate
runs produced bit-identical files. The release also carries rclone-licenses.txt: the full licence
text of rclone and of every Go module listed below, collected at build time.
